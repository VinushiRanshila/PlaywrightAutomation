#SauceDemo Checkout Automation Testing

## Project Overview

This project automates the checkout process of the SauceDemo website using **Playwright with TypeScript**.

The automation script performs login, adds a product to the shopping cart, completes the checkout process, and verifies whether the order is successfully placed.

**Website:** https://www.saucedemo.com/

## Technologies Used

- Playwright
- TypeScript
- Node.js
- Visual Studio Code
- Git and GitHub

## Test Scenario: Checkout Process

1. Navigate to the SauceDemo website.
